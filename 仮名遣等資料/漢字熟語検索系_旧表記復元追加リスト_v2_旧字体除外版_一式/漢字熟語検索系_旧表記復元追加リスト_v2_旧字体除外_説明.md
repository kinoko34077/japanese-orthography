# 漢字熟語検索系 旧表記復元追加リスト v2 旧字体除外版

## 方針

v1に含まれていた `學→学`、`國→国`、`體→体`、`氣→気` 等の旧字体・新字体対応は、一字単位の対応表で処理すべき領域であるため、熟語単位の復元ルールから全件除外した。

## 結果

- v1実行用置換ルール: 1042件
- v2実行用置換ルール: 0件
- 除外ログ: 1042件
- 除外親字対応: 106件

## 実装上の扱い

- `置換ルール.csv` は空表。変換エンジンへ投入しない。
- `除外ログ.csv` は、v1から何を除外したかを確認するための監査用。
- `親字集計.csv` は、旧字体一字対応表へ移管すべき親字一覧。
- 今後の「漢字・熟語検索系」追加リサーチでは、旧字体・新字体の単純一字対応は登録しない。
- 熟語単位で登録するのは、同音異字・異字書換・語単位でなければ誤爆するものに限定する。

## 除外例

| 除外された熟語ルール | 移管先 |
|---|---|
| 学校→學校 | 学→學 の一字対応 |
| 国語→國語 | 国→國 の一字対応 |
| 体験→體驗 | 体→體、験→驗 の一字対応 |
| 気象→氣象 | 気→氣 の一字対応 |
