# 多対一統合・個数判定・例外方式整理 v1

旧字体一字対応の中でも、現代表記側で複数の旧字・本来字が合流したものを対象に、熟語マッピング維持か、一字変換＋例外保護に寄せるかを整理した表。

## 判定概要

|字|復元関係|v1熟語候補数|例外候補数|推奨実装|判断理由|
|---|---|---:|---:|---|---|
|弁|弁→辯/辨/瓣/弁|60|7|熟語マッピング維持|多目標分岐が大きい|
|予|予→豫 / 予保持|39|8|一字変換＋例外|旧字由来が多く、本来字は主に一人称|
|余|余→餘 / 余保持|46|12|一字変換＋例外|旧字由来が多く、本来字は主に一人称・余所系|
|台|台→臺、台風→颱風、台頭→擡頭候補|44|4|一字変換＋上書き|台風系など少数例外だけ語単位で上書き|
|芸|芸→藝 / 芸香系保持|31|5|一字変換＋例外|藝由来が多く、本来字は植物系に偏る|
|欠|欠→缺 / 欠伸等保持|34|6|一字変換＋例外|缺由来が多く、本来字は欠伸・部首説明など少数|
|虫|虫→蟲 / 部首説明保持|28|4|一字変換＋例外|通常語はほぼ蟲由来。虫本来字はメタ語中心|
|缶|缶→罐 / 古器・部首説明保持|19|2|一字変換＋例外|日常語は罐由来。本来缶は古器・部首説明中心|
|注|注釈系→註 / 注ぐ・注意系保持|6|8|熟語マッピング維持|注本来語が多く、註へ一字変換不可|

## 実装原則

- 弁・注は熟語マッピング維持。
- 予・余・台・芸・欠・虫・缶は、一字変換を基本に、先に例外語を保護する方式へ圧縮可能。
- 台風系・台頭系のように主復元字と異なるものは、上書き熟語として保持する。
- 本表は告示PDF由来リストと分けるため、既存告示PDF系との同一ルール重複は実行辞書化しない。
